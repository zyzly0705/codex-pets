# 🌸 Yoyo 桌面宠物 — Wiki 首页

> Yoyo 是一个 Electron 桌面宠物应用，宠物是一个 4-5 岁的小女孩 Yoyo，专为妈妈（教师）打造的温馨桌面伙伴。

## 产品定义

Yoyo 的定位不是泛用 AI 助手，也不是单纯卖角色内容的桌面摆件。

Yoyo 的正式产品定义是：

**一个住在你电脑桌面上的养成型陪伴宠物。**

它通过桌面常驻、小屋照顾、连续需求、情绪反馈和关系成长，让用户每天愿意看她一眼、照顾她一下。

### 核心价值

- `桌面存在感`：角色长期常驻，不只是一次性特效
- `生活照顾闭环`：围绕饱腹、清洁、心情、体力这些状态给出行动入口
- `低打扰互动`：能回应用户，但不抢任务主视线
- `连续关系感`：会记住近期状态和互动，形成陪伴连续性

### 非目标

- 不做深度情感 AI 陪聊产品
- 不做复杂任务管理主工具
- 不做角色商城/DLC 平台优先产品

当前角色结构也遵循这个原则：`Yoyo` 是主角色，像 `gaga` 这样的内容更适合作为 `Yoyo` 的特殊形态，而不是平级的第二主角色。

### 后续迭代判断标准

如果一个功能不能强化“养成、照顾、关系、生活感”，就应该降级、弱化，或者删除。

## 项目简介

Yoyo 桌面宠物是一款轻量级的桌面伴侣应用，她会：

- 🎭 根据天气、时间、情绪自主表现不同行为（散步、跳舞、看书、荡秋千...）
- 💬 用小女孩的口吻和妈妈聊天、撒娇、提醒喝水吃饭
- 🧠 拥有记忆系统，记住和妈妈的互动历史，会"记仇"也会撒娇
- 💗 拥有情感系统（PAD 三维模型），情绪会影响行为和说话语气
- 🌱 拥有成长系统，从「小豆芽」逐渐成长为「小天使」
- 🧗 会攀爬窗口和屏幕边缘，到处探险
- 🎁 纪念日自动庆祝（生日、教师节、母亲节...）
- ⏰ 智能提醒妈妈喝水、吃饭、休息，检测加班提醒
- 🖱️ 支持拖拽、抚摸、喂食、鞭打等丰富交互

## 快速开始

```bash
# 安装依赖
npm install

# 本地运行
npm start
```

## 技术栈一览

- **框架**: Electron ^36.2.0
- **打包**: electron-builder ^26.0.12
- **语言**: 纯 JavaScript（无框架，原生 Canvas 渲染）
- **窗口管理**: node-window-manager（攀爬功能依赖）
- **天气**: Open-Meteo API（免费无需 key）
- **存储**: localStorage（记忆/成长/设置数据）
