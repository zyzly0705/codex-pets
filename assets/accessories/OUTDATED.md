# Legacy Outfit Assets

These accessory and outfit source assets are **outdated**.

They were created for an earlier iteration of Yoyo's appearance system and should **not** be treated as final production visuals.

Current status:

- The existing files are only kept so the app can continue running.
- Visual matching, silhouette fit, and outfit completeness are not reliable enough for final use.
- Future outfit work should be based on a full redesign, not on incremental tweaks to this legacy set.

When redesigning, prefer:

- complete outfit concepts over free-form accessory stacking
- model-matched silhouettes over generic decorative props
- a small set of high-quality looks over a large set of mismatched options
